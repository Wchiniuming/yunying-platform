## 1. 项目概述

### 1.1 项目背景

| 项目 | 说明 |
|------|------|
| 项目名称 | 麻辣鸡外卖订单管理平台 |
| 项目类型 | 轻量级外卖订单 + 顾客CRM管理系统 |
| 运营模式 | 纯外卖配送 (无堂食/无线下门店) |
| 接单渠道 | 个人微信号接单 |
| 配送方式 | 自送 + 第三方平台 (顺丰同城等) |
| 当前痛点 | 微信接单后手动记录到Excel,数据分散难以分析 |
| 订单量 | 刚起步, <50单/天 |

### 1.2 项目目标

1. **订单全记录** - 将所有外卖订单统一录入平台,告别Excel
2. **顾客画像** - 建立顾客档案,记录口味偏好、复购情况
3. **配送追踪** - 记录配送状态,确保每单可追溯
4. **数据分析** - 提供基础统计报表,辅助运营决策

### 1.3 业务边界

**本期包含:**
- 订单录入与管理
- 顾客档案与标签管理
- 配送状态追踪
- 基础数据统计

**本期不包含:**
- 微信/支付宝支付对接
- 小程序/公众号开发
- 线下门店点餐模块
- 库存/采购管理
- 员工排班/绩效

### 2.2 订单管理

#### 2.2.1 新增订单

**功能描述:** 手动录入微信接单的订单信息

**录入字段:**

| 字段组 | 字段名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| 基础信息 | 订单编号 | 自动生成 | - | 格式: WX_YYYYMMDD_XXX |
| | 接单时间 | datetime | ✓ | 默认当前时间,可修改 |
| | 订单来源 | select | ✓ | 微信客户群/微信个人号/朋友圈 |
| 顾客信息 | 顾客微信名 | string | ✓ | 来自微信消息 |
| | 关联顾客 | select | - | 选择已有顾客或新建 |
| | 手机号 | string | - | 配送联系电话 |
| | 配送地址 | string | ✓ | 详细地址 |
| 商品明细 | 商品列表 | json | ✓ | 支持多商品 |
| | - 商品名称 | string | ✓ | |
| | - 单价 | decimal | ✓ | |
| | - 数量 | int | ✓ | |
| | - 规格 | string | - | 大份/中份/小份 |
| | - 口味 | string | - | 麻辣/中辣/微辣/不要辣 |
| | - 备注 | string | - | 不要香菜等 |
| 金额信息 | 商品总价 | decimal | 自动 | 自动计算 |
| | 包装费 | decimal | - | 默认0 |
| | 配送费 | decimal | - | 默认0 |
| | 优惠减免 | decimal | - | 手动输入 |
| | 实收金额 | decimal | ✓ | |
| 配送信息 | 配送方式 | select | ✓ | 自送/顺丰/其他 |
| | 骑手姓名 | string | - | |
| | 骑手电话 | string | - | |
| | 期望送达 | datetime | - | |
| | 配送备注 | string | - | 门牌号等 |
| 支付信息 | 支付状态 | select | ✓ | 已支付/未支付 |
| | 支付方式 | select | - | 微信/支付宝/现金 |
| 扩展信息 | 备注 | text | - | 特殊说明 |

**交互要求:**
- 顾客微信名输入时,自动联想已有顾客
- 选择关联顾客后,自动填充地址和手机号
- 商品支持快速添加,扫码/搜索菜品
- 金额自动计算,优惠后实收金额手动确认

#### 2.2.2 订单列表

**功能描述:** 展示所有订单,支持筛选和搜索

**列表字段:**
- 订单编号
- 接单时间
- 顾客微信名
- 商品摘要 (如: 麻辣鸡x1 + 凉菜x1)
- 实收金额
- 配送方式
- 订单状态
- 操作 (查看/编辑/删除)

**筛选条件:**
- 日期范围 (默认今日)
- 订单状态
- 配送方式
- 顾客 (模糊搜索)
- 支付状态

**排序:**
- 默认按接单时间倒序
- 支持按金额/状态排序

#### 2.2.3 订单详情

**功能描述:** 查看订单完整信息

**展示内容:**
- 全部录入字段
- 订单状态时间线 (接单→制作中→待取餐→配送中→已送达)
- 关联顾客档案入口
- 操作日志 (谁在什么时间修改了什么)

#### 2.2.4 订单状态流转

```
┌─────────┐    ┌──────────┐    ┌──────────┐    ┌─────────┐    ┌────────┐    ┌────────┐
│ 待接单  │───→│ 制作中   │───→│ 待取餐   │───→│ 配送中  │───→│ 已送达 │───→│ 已完成 │
└─────────┘    └──────────┘    └──────────┘    └─────────┘    └────────┘    └────────┘
     │              │               │               │
     ↓              ↓               ↓               ↓
  ┌────────┐    ┌────────┐     ┌────────┐     ┌────────┐
  │ 已取消 │    │ 已取消  │     │ 已取消  │     │ 已取消  │
  └────────┘    └────────┘     └────────┘     └────────┘
```

### 2.3 顾客管理

#### 2.3.1 顾客列表

**列表字段:**
- 顾客微信名 (昵称 + 备注名)
- 手机号
- 常用地址
- 标签 (颜色标签)
- 累计下单次数
- 累计消费金额
- 最近下单日期
- 客户等级
- 操作

**筛选条件:**
- 关键词搜索 (微信名/手机/地址)
- 标签
- 客户等级
- 下单时间范围

**排序:**
- 默认按最近下单排序
- 支持按消费金额/下单次数排序

#### 2.3.2 新建/编辑顾客

**录入字段:**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 顾客微信名 | string | ✓ | |
| 微信备注名 | string | - | |
| 手机号 | string | - | |
| 常用地址 | string | - | |
| 客户等级 | select | - | 普通/常客/VIP/SVIP |
| 来源 | select | - | 微信群/朋友圈/朋友推荐/其他 |
| 标签 | multi-select | - | 从预置标签选择 |
| 口味偏好 | select | - | 麻辣/中辣/微辣/不要辣/五香 |
| 忌口 | multi-select | - | 香菜/葱蒜/海鲜过敏等 |
| 会员积分 | int | - | 预留字段 |
| 累计消费 | decimal | - | 自动汇总 |
| 备注 | text | - | |

#### 2.3.3 顾客详情

**展示内容:**
- 基本信息
- 标签管理
- 累计订单数/消费金额
- 订单记录列表 (该顾客所有订单)
- 消费趋势图
- 备注修改日志

#### 2.3.4 顾客分析

**统计维度:**
- 新增顾客数 (日/周/月)
- 复购率
- 流失顾客预警 (X天未下单)
- 高价值顾客排名 (TOP N)
- 顾客消费分布

### 2.4 标签管理

#### 2.4.1 预置标签分类

| 分类 | 标签 |
|------|------|
| 口味偏好 | 重辣, 中辣, 微辣, 不要辣, 麻辣, 五香 |
| 忌口 | 不要香菜, 不要葱蒜, 不要辣椒, 海鲜过敏, 坚果过敏 |
| 客户等级 | 普通, 常客, VIP, SVIP |
| 消费特征 | 高消费, 价格敏感, 薅羊毛 |
| 来源 | 微信群, 朋友圈, 朋友推荐, 自然流量 |
| 特殊 | 投诉过, 退款多, 需重点关注 |

#### 2.4.2 自定义标签

- 支持新建自定义标签
- 支持标签颜色编辑
- 支持标签分类

### 2.5 配送管理

#### 2.5.1 配送状态看板

**分组展示:**
- 待取餐 (顺丰待取/自送待出)
- 配送中
- 已送达
- 异常件 (超时/拒收)

**快捷操作:**
- 一键更新状态
- 联系骑手 (点击拨号)
- 标记异常

#### 2.5.2 配送方式管理

**支持配置:**
- 自送 (自己配送)
- 顺丰同城
- 其他第三方

**各方式字段:**
| 配送方式 | 特有字段 |
|----------|----------|
| 自送 | 配送人, 联系电话 |
| 顺丰 | 顺丰运单号, 骑手姓名, 骑手电话 |
| 其他 | 平台名称, 骑手姓名, 骑手电话 |

**支持导出:**
- 订单列表 (Excel)

- 自定义报表
