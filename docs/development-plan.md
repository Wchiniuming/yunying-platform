## 1. 项目概述

### 1.1 项目目标

开发一套轻量级外卖订单管理平台,支持:
- 订单全链路记录 (接单→制作→配送→完成)
- 顾客CRM管理 (复购、口味偏好、VIP标签)
- 配送状态追踪 (自送 + 顺丰)
- 基础数据统计

### 1.2 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| 桌面框架 | Electron | 打包成Windows exe |
| 前端框架 | Vue 3 | 渐进式JS框架 |
| UI组件库 | Element Plus | Vue3组件库 |
| 数据库 | SQLite | 零配置,单文件 |
| ORM | better-sqlite3 | Node.js原生SQLite |
| 构建工具 | Vite | 快速构建 |
| 打包工具 | electron-builder | 打包Windows安装包 |

### 1.3 核心特性

- **零配置**: 用户双击exe即可使用
- **离线运行**: 无需网络
- **安全升级**: 程序与数据分离,升级不丢数据
- **轻量级**: <50单/天完全够用

## 5. 升级机制

### 5.1 目录结构

```
程序目录: C:\Program Files\MalaJi\     ← 升级时覆盖
数据目录: %APPDATA%\MalaJi\            ← 升级时永不触碰
```

### 5.2 升级流程

1. 开发者打包: `npm run build:win` → 生成exe
2. 拷贝exe到目标机器 (U盘/局域网)
3. 关闭当前应用
4. 双击新版本安装包
5. 选择保留用户数据
6. 完成升级,数据完整

### 5.3 数据备份

```
定期备份: 复制 %APPDATA%\MalaJi\data\malaji.db 到安全位置
迁移数据: 复制整个data文件夹到新电脑对应目录
```

## 6. 开发环境

### 6.1 必要组件

| 组件 | 版本 | 说明 |
|------|------|------|
| Node.js | 18+ | 开发时使用 |
| VS Code | 最新 | 推荐IDE |
| Git | 任意版本 | 版本控制 |

### 6.2 本地启动

```bash
# 1. 克隆代码
git clone <repo-url>
cd mala-ji-platform

# 2. 安装依赖
npm install

# 3. 开发模式
npm run dev
# 自动打开浏览器 http://localhost:5173

# 4. 打包 (开发完成后)
npm run build:win
# 生成: dist/MalaJi-Setup-1.0.0.exe
```
